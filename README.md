# Nexus AI Automation

Modern, Futuristic AI Business Automation Website built with Next.js 15, React 19, Framer Motion, and Tailwind CSS.

## Getting Started

1. Install dependencies:
   bash
   npm install
   

2. Run the development server:
   bash
   npm run dev
   

3. Open [http://localhost:3000](http://localhost:3000) with your browser.
